# CashRunway
Simple, available data can warn a small business of a cash crunch early enough to act.

The biggest reason small businesses fail is due to cash shortfalls. This tools lets users to predict when this shortfalls are coming for Construction industry. The reason, I chose construction is because they have spendings prior and during the project and usually the full payout only after the project is done. The product will be done when after user's input of spending there will be warning about the shortfall comings with a weekly/monthly chart. As well as with couple main drivers behind this shortfall.
